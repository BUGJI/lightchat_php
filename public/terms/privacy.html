🔒 隐私政策

更新日期：2026 年 5 月 28 日

生效日期：2026 年 5 月 28 日

本隐私政策说明了本聊天系统（以下简称"本系统"）如何收集、使用和保护用户信息。请仔细阅读。

一、我们收集的信息

  1. 账号信息：用户名、邮箱地址、密码（加密存储）、联系方式（可选）。
  2. 登录信息：登录时间、IP 地址、浏览器 User-Agent。
  3. 聊天内容：用户在频道和私聊中发送的文本消息、文件链接。
  4. 上传文件：用户上传的图片、文件及元数据。

二、信息的使用

  1. 提供聊天服务的基本功能。
  2. 维护系统安全和防止滥用。
  3. 遵守中国法律法规的合规留存要求。

三、信息的存储

  1. 所有数据存储在服务器本地，不会传输给第三方。
  2. 聊天记录以明文形式存储，用于合规审计。
  3. 密码使用 bcrypt 哈希加密，不可逆。
  4. 登录 IP 和审计日志用于安全回溯。

四、信息的共享

  1. 本系统不会向任何第三方出售、出租或共享用户个人信息。
  2. 除非收到合法的执法请求，否则不会披露用户数据。

五、信息安全

  1. 采用 bcrypt 加密存储密码。
  2. 使用 Token 认证机制保护 API 访问。
  3. 支持 HTTPS 加密传输（依赖服务器配置）。

六、用户权利

  1. 用户可随时查看和修改自己的个人资料。
  2. 用户可申请删除自己的账号及关联数据。
  3. 用户可导出自己的聊天记录。

七、未成年人保护

本系统不针对未成年人设计。如果您是未成年人，请在监护人指导下使用。

八、政策更新

我们可能会不时更新本隐私政策，更新后的版本将在本页面发布。

九、联系方式

如有任何疑问，请联系系统管理员。
